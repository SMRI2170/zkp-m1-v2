## 0. 何を解く技術を探すのか

観測者Aが10:00、Bが11:00、Cが翌日、と**異なるフレーム**を各1つのRSSIで観測する。Remote IDの位置・時刻・IDは**不信頼な申告**。受信機のGPS・受信時刻・RSSIはまず正直な受信端末による測定と仮定し、真正性は別課題とする。送信電力は未知、強い攻撃者モデルでは**フレームごとに独立・任意**。観測件数1000以上も想定する。

成果物と保証を混同しない。

- **Task 1 RSSI予測**：位置・条件が与えられたとき、どんなRSSIが観測されそうか。
- **Task 2 距離推定**：RSSIから実際の送受信距離の点推定／確率分布／上下限を出せるか。
- **Task 3 異常検出**：申告位置に基づくRSSIモデルから外れているか。
- **Task 4 原因識別**：送信電力操作・位置偽装・遮蔽・端末誤差のいずれかを分離できるか。
- **Task 5 ZKP**：秘密の受信位置とRSSIを使った*定められた計算*が正しいことを証明できるか。

Task 1 ができても Task 2/4 が成立するとは限らない。Task 5 は Task 2/4 の物理的な識別可能性を作らない。

### 最小の測定モデル

\`\`\`text
r[k] = a[k] + b[j(k)] - 10*n[k]*log10(d_real[k]/d0) + fading[k] + noise[k]
d_real[k] = ||p_real[k] - receiver_position[j(k)]||
d_claim[k] = ||p_claim[k] - receiver_position[j(k)]||
\`\`\`

a[k] は送信電力・アンテナ等を吸収した**実効的な基準受信電力**で、測定されたEIRPではない。p_claim は機体の自己申告であり正解ラベルではない。RIDの速度・時刻も同じく不信頼な特徴量である。

**識別可能性の下界：** 1フレーム1RSSIで a[k] が毎回自由なら、任意の候補距離 d'[k]>0 に対して \`a'[k]=r[k]-b[j(k)]+10*n[k]*log10(d'[k]/d0)-fading[k]-noise[k]\` と置ける。1000件に増やしても毎回独立な a[k] が増える。**学習法の優劣以前の非識別性**。観測方程式・拘束が増えない限り、距離や送信電力の真値は同定不能。

表の「M0」は**フレームごと単一RSSI・全ノード非同期・各送信出力が独立に無制約**という本来条件。

| T02 | WLS/ML/非線形最小二乗/SDP（同時推定） | 位置、共通の未知a、n | 複数地点の独立観測／共通a等 | **不可** | 既存未知電力測位の再現 |

| T07 | Kalman/EKF/UKF/粒子フィルタ・HMM | 時系列の隠れ状態 | 状態変化率・移動・電力遷移モデル | **保証不可** | 長時間ギャップ効果 |

| T09 | Radio Map/指紋照合・補間 | 位置候補／RSSI予測 | 信頼できる事前収集、電波源/環境の安定性 | **保証不可** | 学習場所外の一般化 |

| T12 | GLRT/変化点検出/CUSUM/尤度比 | RSSIモデルからの異常 | 正常分布と攻撃/変化の区別可能性 | **保証不可** | 送信電力変化の**疑い** |
| T13 | Conformal Prediction / 予測区間校正 | 予測区間、保留 | 交換可能性/時間依存への適切な校正 | **保証不可** | 区間包含率・保留率 |
| T14 | RSSIヒストグラム・受信率・欠測のモデル | 統計的な受信特性 | 受信窓/検出閾値、機材差、欠測ログ | **保証不可** | 追加の受信側特徴 |
| T15 | 受信側多アンテナの電力差（指向性RSSI） | 方位・整合 | 同一イベント内に複数受信分岐、較正済みアンテナ | **不可**（M0を変更） | 追加RFハードの別案 |
| T16 | Circom/Groth16・ZKML/EZKL・Nova | 計算/状態更新の暗号証明 | 証明できる決定的計算、入力拘束・モデル固定 | **不可**（物理情報は増えない） | T01/T05/T12から小さな回路 |
| T17 | 秘密共有・MPC・コミットメント／署名 | 秘密統計・改ざん検知 | 鍵、脅威モデル、複数サーバ構成等 | **不可** | プライバシーの比較 |

## 3. 「完全非同期・自由送信電力」でも試せる研究は何か

### 3.1 そのまま使える：計算・評価の枠組み（ただし物理距離保証は不可）
- **T01 + T06**：申告距離で逆算した必要送信電力 \`a_required[k]\` の階層ベイズモデル。ただし申告位置自体が虚偽なら真の送信電力ではない。妥当な事前分布を外れると \`UNKNOWN\`。
- **T08 + T11**：環境別GP・頑健残差。必要なのは**独立真値を持つ校正飛行**と分布外評価。予測残差は「送信電力操作の確定」ではない。
- **T12 + T13**：変化点/尤度に基づく異常と判断不能の区別。正常時の誤警報を厳格に測定する。
- **T16**：上記の**実行可能な確定的計算**だけを固定小数点にして証明。モデルへの信頼仮定、commitment/版/時刻の整合は別途検証。

### 3.2 別の観測条件が必要な研究
- **T02/T03/T04/T15**：同一イベントで別の独立RSSIが得られるなら、共通送信電力を消去する構成が検討できる。ただし**受信ハード・観測モデルの変更**なのでM0との比較ベースラインに限定。
- **T05**：規格上のEIRPの許容範囲と校正済み伝搬モデルから**可能距離区間**を推定。ただしEIRP≠基準受信電力 \`a\`。また**出力規制を破る攻撃者への保証を規格適合前提から導かない**。
- **独立の真距離/位置アンカー**：研究室管理下のRTK・既知距離のRF実験などで一部のデータに教師信号を付ける。これは**学習・評価条件の変更**であり、不信頼RID申告を正解ラベルに代用しない。

### 3.3 無理に結論にしないもの
- 「送信電力が変わった」はRSSI変化だけからは断定できない。別原因（真距離、遮蔽、姿勢、アンテナ方向、受信機差）もある。
- 学習の予測RSSIが合ったことは実位置の正しさではない。逆に外れ値は位置偽装の確定ではない。
- RID申告に存在する速度・位置・時刻を機体の物理的真値と扱わない。
- Nova/MPC/BC/機械学習によって「任意の送信電力」が相殺されたと主張しない。

## 4. 技術を比較する実験の共通仕様（まだ実装しない）

**主目的：どの情報／仮定を足したときに、識別可能性と推定品質がどう変わるかを評価する。**

| 軸 | 比較条件 |
|---|---|
| データ | 合成（完全な真値あり）／実RF（RTK等で真値あり）／真値なしの現場RID（教師なし用途のみ） |
| 観測 | 1フレーム1RSSI、10秒・1時間・1日間隔、1/2/3台の非同期ノード |
| 累積数 | 10 / 100 / 500 / 1000 / 5000 |
| 送信電力 | 未知一定／緩変動／確率変動／急変／**フレームごと敵対的に独立** |
| 攻撃 | 正常／位置申告偽装／送信電力操作／両方／学習データ汚染／再送・ID偽装 |
| 伝搬誤差 | n変化、受信機オフセット、遮蔽、反射、端末姿勢、欠測 |
| 手法 | T01・T06・T07・T08・T10・T11・T12・T13、別構成のT03 |
| 物理指標 | RSSI MAE/RMSE、**真距離**MAE/RMSE、信頼/予測区間の包含率、FPR/TPR、保留率、分布外頑健性 |
| 計算指標 | CPU、RAM、時間、モデル学習/推論時間、証明時間・サイズ・検証時間（ZKP段階） |
| 保証区分 | 理論的識別性／統計的精度／暗号学的計算検証／実測された物理真正性を分ける |

**推奨する採否ゲート**
- **P0：文献再確認** — 各論文の式・観測の同時性・出力仮定・正解ラベル・検出対象を1枚の表にして出典箇所付きで凍結。
- **P1：非識別性の再現** — M0に対し異なる実距離と送信電力系列が**完全に同じRSSI**を生成する反例を実装。事実の基準線。
- **P2：条件付き推定** — T01/T06/T08/T12から最小構成を比較。追加した仮定、独立真値、予測区間の包含率を報告する。
- **P3：対照としてDRSS** — 同一パケット複数RSSIの別構成を追加して、何が変わると原理的に改善するかを測る。
- **P4：ZKP** — P2/P3で評価した**固定された判定・推論**を再現し、秘密入力と公開出力の拘束、量子化誤差、否定テストを確認する。

### 今回はここまで。方式選定・ハード購入・新規性の確定はしない

まず技術の全体像と一次資料の正確な条件を揃え、**「本来条件に適合するのか」「条件付きに予測できるだけなのか」「追加ハードが要るのか」**で評価する。今週の最初の成果物はこのサーベイと対応する比較表であり、実証済みでない性能値は書かない。

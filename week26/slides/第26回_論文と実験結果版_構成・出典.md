## 主要な実験と、結論の範囲

| 対象 | 条件 | 結果から言えること |
|---|---|---|
| 位置と電力の改変 | 合成。各送信は単独受信。攻撃者は受信機位置と伝搬モデルを既知。外向き100m | 警報は正常5.02%、位置のみ23.88%、無制限の電力連動2.42%。受信率も86.8%から68.3%へ変わるため、全送信を隠した結果とはしない |
| 非同時の台数比較 | 同じ総データ・真距離・電力を1〜10台へ割当て。各送信1台 | 警報・MAEは小差。カバー範囲や観測数を増やす便益はこの対照では未評価 |
| 観測1000件 | 単純な距離減衰モデルの同値な2世界 | 距離4倍・電力約12.04dB増加でRSSI一致。件数だけで一意化する主張への反例 |
| 履歴 | 過去の独立真距離付き点検、電力相関時間10分を仮定 | 3秒前の履歴は距離誤差を低減。1時間後の過去値維持は悪化。普遍的な有効時間ではない |
| RID別補正 | 合成の独立真距離ラベル。個体差SD6dB・飛行差SD1dB、30ラベル | 通常MAE41.35→19.17m。同名別送信機では40.96→54.33m。位置偽装検知率や機体認証ではない |
| LoRaの時刻ずれ | 公開実測系列への人工的な時刻ずれ | 正常誤警報が0秒約4.87%から15秒約23.22%。実RIDの複数受信実験ではない |
| 同じ送信の複数受信 | 別方式。共通3D軌跡・5受信機・伝搬既知・対応既知、合成10 seed | 水平100m改変の検知率は雑音SD2dBで約73.7%、SD6dBで約18.7%。元の非重複条件を解いた結果ではない |
| 一部重複 | 同上。0〜5台が受信。受信範囲と欠測を簡略化 | 判定可能77.1%、その中の検知64.0%、全送信中の警報49.35%。保留22.89%を分離 |
| 配置の反例 | 円周地上4台、中心上空80m／20m、雑音なし | 電力差−2.18dBで全RSSIが一致。複数台でも常に位置を区別できるとは言えない |

## 論文の出典

1. Keizer, Sciancalepore, Oligeri, GhostBuster, CCNC 2024. [DOI](https://doi.org/10.1109/CCNC51664.2024.10454860)。本文VI-Cの仮想12受信機・5パケットの報告値。364m／1175mは偽装変位であり、一般的な検知可能距離ではない。
2. Hu, Leus, Robust Differential Received Signal Strength-Based Localization, IEEE TSP 65(12), 2017. [DOI](https://doi.org/10.1109/TSP.2017.2684741)。共通電力と差分の電力偏差を区別。
3. Liほか, Experimental Validation of Cooperative RSS-based Localization with Unknown Transmit Power, Path Loss Exponent, and Precise Anchor Location, IEEE TWC 2024. [原文](https://arxiv.org/html/2406.14664v1)。対象ごとの共有電力と複数リンク。50ノードBLE実験。送信ごとの任意電力への偽装耐性実験ではない。
4. Santosほか, Recursive Estimation of Dynamic RSS Fields Based on Crowdsourcing and Gaussian Processes, arXiv:1806.02530v2, 2018. [原文](https://arxiv.org/html/1806.02530v2)。RSS分布の逐次推定。RID偽装検知の保証ではない。
5. Maviliaほか, An experimental dataset using UAVs and LoRa technology in avalanche scenarios, Data in Brief 2025. [DOI](https://doi.org/10.1016/j.dib.2025.112243)。[データv2](https://zenodo.org/records/17339095)。固定雪中送信機からUAV受信機へ送信。
6. [屋内BLE公開データ](https://github.com/manwestc/ble-rssi-indoor-localization-dataset)。固定コミットb38a9a4a53a01f52136f4e9b29b5045f61655a06。

全論文のアルゴリズムを再現したとの主張はしない。[条件の詳しい照合](../18_教授の問いに対応する関連論文と分かること.md)。実測の生座標・秘密鍵・捕捉記録はスライドに収録しない。

# Week26：未知送信電力と非同期単一RSSIの合成シミュレーション結果

**実行日：2026-11-01**／**合成データのみ。実機RF評価・ZKP証明は未実施。**

先行資料：[00 技術サーベイ](./00_関連技術サーベイと適用条件.md)、[01 前提と事実](./01_研究前提と確認済み事実_識別可能性.md)、[02 技術深掘り](./02_技術深掘り_モデル比較と検証計画.md)、[Issue #67](https://github.com/SMRI2170/zkp-m1-v2/issues/67)。

## 1. 結論

1. **距離推定は条件付きで可能。** 校正に用いた送信電力分布を保つ場合、Bayesian/GP/MLPはRSSIから距離を統計的に予測できた。
2. **送信電力の分布シフトでは信頼区間が崩れる。** 一定の出力が8dB変わるだけでも、Bayesianの90%区間の実包含率は36.93%となった。
3. **送信電力操作と位置偽装を連動させる攻撃はRSSI整合性検査を回避できる。** 正常警報率5.53%に対し、同時偽装では5.20%だった。
4. **単一RSSI・イベントごと任意電力の距離識別は原理的に不可能。** 1,000観測の同値反例を実行した。

## 2. データとモデル

- 受信機3台が**1時間ずつ別の送信イベント**を観測。1イベント1RSSIのみ。**同一パケット差分は用いない。**
- 真距離5〜150m、log10距離一様、伝搬指数n=2、独立雑音σ=2.5dB、受信機のオフセットを既知として補正する、実環境より有利になり得る単純モデル。
- 1m基準の実効受信電力aは約-42dBm。**実際の送信EIRPを測定した値ではない。**
- 真距離ラベル付き合成訓練1000件、正常校正500件、各テスト条件1500件。学習時の電力変動はσ=3dB。seed=20261101。
- 比較：校正済みPath Loss点推定、対数距離のTruncated Gaussian Bayesian 90%区間、1変数GP＋conformal区間、1変数MLP(24×24)＋conformal区間。
- 送信電力5条件：(a)未知一定・校正済み、(b)未知一定+8dB校正ずれ、(c)確率変動σ3dB、(d)大変動σ10dB、(e)30m分類を反転させる敵対的電力＋申告位置偽装。

## 3. 距離MAE（m）

| 条件 | 物理式 | Bayesian | GP | MLP |
|---|---:|---:|---:|---:|
| 一定・校正済 | 9.10 | 8.72 | 8.85 | 8.98 |
| 一定・+8dBの校正ずれ | 24.70 | 24.33 | 24.16 | 24.23 |
| 確率変動σ3dB | 13.13 | 11.81 | 11.94 | 11.94 |
| 大変動σ10dB | 28.78 | 25.11 | 24.92 | 25.69 |
| 適応的電力＋偽位置 | **61.03** | **57.06** | **56.31** | **56.21** |

### Bayesian：90%距離区間／30m判定

| 条件 | 実包含率 | 30mの上下を判定した率 | 全件中、誤った判定 |
|---|---:|---:|---:|
| 一定・校正済 | 97.67% | 58.07% | 0.00% |
| 一定・+8dBずれ | 36.93% | 62.93% | 6.73% |
| 確率変動σ3dB | 89.53% | 56.53% | 0.27% |
| 大変動σ10dB | 53.73% | 66.20% | 11.53% |
| 適応的電力＋偽位置 | **9.00%** | 62.07% | **61.93%** |

30m判定は計算上の区間が30mを跨がないという意味。法令違反や実距離の物理的確定ではない。特に敵対的条件では**誤った距離に自信を持つ**。

## 4. 申告座標を使う残差の異常検出

申告位置までの距離 d_claim に対し a_required = RSSI_calibrated + 20 log10(d_claim) を計算。正常校正データで約5%の警報を出す閾値を設定。**a_requiredは実電力の測定値ではない**。

| 条件 | 警報率 |
|---|---:|
| 正常σ3dB（申告は真） | 5.53% |
| 送信電力だけ+8dB（申告は真） | 57.60% |
| 送信電力だけσ10dB（申告は真） | 45.47% |
| 適応的な送信電力操作（申告は真） | 86.73% |
| 位置偽装だけ・通常の電力 | 89.47% |
| **位置と送信電力を連動して偽装** | **5.20%** |

連動偽装では a_attack = a_normal + 20 log10(d_true/d_claim) と選ぶと、測定RSSIが**偽装した距離にいる正常な送信機**と同じ分布になる。送信電力操作と位置偽装はRSSI残差だけで原因特定できない。攻撃者が送信条件を選べるという強い脅威モデルの反例である。

今回必要となった電力偏差は**−33.1〜+28.1dB**。実機でその範囲を操作できることや法規適合を示す結果ではない。

## 5. 1000件の識別不能反例（実行確認済）

RSSI = a − 20log10(d) とする。各イベントで d2 = 4*d1、a2 = a1 + 20log10(4) = a1 + 12.0412dB とするとRSSIは全て等しい。1,000観測で計算した**最大差1.42e−14dB**は浮動小数点の丸め誤差。

**GitHubで単独実行できる再現コード：** [identifiability_minimal.py](https://github.com/SMRI2170/zkp-m1-v2/blob/main/experiments/week26-rssi-privacy/identifiability_minimal.py)。

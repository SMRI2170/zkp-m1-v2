## 0. 最初に研究成果の種類を厳密に分ける

「RSSIから距離を推定」「送信電力を検出」「位置偽装を検出」は別問題。

| 研究成果 | 与える入力 | 返す値 | 信頼性について主張できる範囲 |
|---|---|---|---|
| RSSI予測 | 申告位置、観測者位置、過去RSSI | RSSIの平均/分散 | **申告位置が正しいと仮定した**条件付き予測 |
| 距離逆推定 | RSSI、送信電力等への仮定 | 距離の点推定/事後分布/区間 | **採用した電力・伝搬モデルのもとで**の推定 |
| モデル異常検知 | 申告位置、RSSI、校正済みモデル | 異常度、保留 | 申告値・出力・伝搬のどれかがモデルと**不整合** |
| 出力操作の原因特定 | RSSIと、出力以外の変動を拘束する**独立証拠** | 出力変動の推定 | RSSIだけの自由Pモデルでは一般に不可 |
| 偽位置の確定 | 申告位置と**独立の実位置/距離証拠** | 位置不一致 | 適切な観測誤差と同一機体対応が必要 |
| ZKP | 秘密の測定値、固定モデル・校正/ルール | 計算証明 | **計算の正しさ**。RFセンサー真値ではない |

### 用語の固定

- `r_k`：イベント `k` に受信機 `j(k)` が測定したRSSI [dBm]。
- `q_k`：Remote IDから受けた**申告**位置 [m]。真位置ではない。
- `p_k`：実際の送信点 [m]（基本的に未知）。
- `x_j`：受信機の実際の位置（観測者が保有）。
- `a_k`：出力・送信アンテナ・基準距離損失を吸収した実効基準受信電力 [dBm]。**実EIRPそのものではない**。
- `n`：伝搬指数、`b_j`：受信機個体オフセット、`e_k`：遮蔽・フェージング・観測ノイズ。

```math
r_k = a_k + b_{j(k)} - 10 n \log_{10}\left(\frac{\lVert p_k - x_{j(k)}\rVert}{d_0}\right) + e_k
```

以降、観測モデルが受信RSSIの対数スケールにおいて近似的に加法的であることを仮定する。

## 1. 識別性・可観測性を先に検証する技術

**技術A：構造的識別可能性（structural identifiability）／反例構成**

単一観測 `r_k` に対して、`p_k` と `a_k` が両方未知で自由。ノイズもゼロとする最も有利なケースですら、候補真距離 `d'_k` に対して

```math
a'_k = r_k - b_{j(k)} + 10n \log_{10}(d'_k/d_0)
```

で同じRSSIを生成できる。実データで「平均誤差が小さかった」だけで、敵対的操作への保証を主張できない。

**調査すべき道具**：逆問題の識別可能性、Jacobianの階数、Fisher Information Matrix / Cramér–Rao Bound (CRLB)、同値な観測列の構成。CRLBはモデルの条件に依存し、非識別の問題では意味のある有限な距離誤差下限が得られない場合がある。単一RSSI・自由aの下では、`r=a-c\log d`の微分が未知数 `(a,\log d)` に対して1行しかなく、局所的な階数が足りない。

**技術B：距離区間（set-membership / bounded-error）**

`a_min ≤ a_k ≤ a_max`、`|e_k|≤E`、`n>0`を**独立に裏付けられる場合だけ**、単一RSSIから許容区間を求められる。

```math
10^{(a_{\min}+b_j-r_k-E)/(10n)}
\le d_k/d_0 \le
10^{(a_{\max}+b_j-r_k+E)/(10n)}
```

これは**実効基準受信電力の上下限**であり、Remote ID規格のEIRP下限をそのまま`a_min`へ入れてはいけない。法規違反を調べるために規格遵守を前提とする循環論法にも注意。区間が30mを跨いだら`UNDETERMINED`を返す。

## 2. 物理式・数値最適化

### 技術C：Log-Distance Path Loss (LDPL) / Free-space

```math
\hat d = d_0 10^{(a+b-r)/(10n)}
```

**測れること**：送信電力・伝搬指数・受信機校正が既知の場合のベースライン。  
**壊れる条件**：送信電力変化、NLOS、マルチパス、アンテナ指向性、受信機姿勢、機種差。  
**研究での役割**：他手法の勝ち負けの基準とし、既知Pでの上限性能も測る。

### 技術D：未知送信電力を位置と同時に推定 — WLS / ML / SDP

代表：Huang et al., Sensors 2016（本文の式(1)-(6)、二段階WLS・PLE事前分布）。本文は2次元で**複数受信機 N**を使う。著者は実機での検証を**将来課題**としているため、シミュレーション性能を実測精度と混同しない。  
代表：Wang et al., IEEE TCOM 2026。幾何的に良好な**複数基地局**を選び、未知Pを含めてSDPで推定。公開要旨では5局・典型的シミュレーション条件で約5m RMSE。

**重要**：「電力の値が未知」と「各測定に異なる自由な電力が割り当てられる」はまったく違う。後者にWLS/SDPだけを当てても欠損情報は増えない。

### 技術E：DRSS / RSS比による共通成分の除去

同一の送信イベントkを受信機i,jが受ける場合、

```math
(r_{i,k}-b_i)-(r_{j,k}-b_j)
=-10n\log_{10}(d_{i,k}/d_{j,k})+(e_{i,k}-e_{j,k})
```

共通の実効基準受信電力が相殺される。*同一イベント*の十分に離れた複数RX、アンテナ差・伝搬誤差の較正が必要。複数の方向性RXで同じパケットの電力比を取れば**方位**を推定する別案もあるが、単独拠点の方位から**半径方向の絶対距離は決められない**。

**本来条件との差**：Aが10:00、Bが11:00に**別パケット**を受けた場合は、`a_{10:00}-a_{11:00}`が残る。**同時／同一パケット受信のDRSSを本来条件での解決とみなさない。**

## 3. Bayesian / Gaussian Process / 時系列モデル

### 技術F：階層Bayesian — 実効送信電力を潜在変数として積分

仮定する一例：

```math
a_k \sim \mathcal{N}(\mu_a,\sigma_a^2),
\qquad
e_k\sim \mathcal{N}(0,\sigma_e^2).
```

このとき**距離dが与えられている場合**、

```math
r_k \mid d_k
\sim\mathcal{N}\big(\mu_a+b_j-10n\log_{10}(d_k/d_0),\;
\sigma_a^2+\sigma_e^2\big).
```

*逆推定*で `z=\log10(d/d0)` に一様な事前密度を仮に置き、`n`を既知とすると、事後は正規形：

```math
z\mid r \sim\mathcal{N}\left(
\frac{\mu_a+b_j-r}{10n},
\frac{\sigma_a^2+\sigma_e^2}{(10n)^2}
\right).
```

**数値感度の例**：`σ_a=6 dB`、`σ_e=4 dB`、`n=2`。すると、95%区間は距離の中央値を**約5.1倍/5.1分の1**した範囲に広がる（単純モデル・例示値）。電力分布を仮定すれば出力値は作れるが、30m離隔の精密な確定判定にはならない。距離・姿勢・nの不確実性を追加すれば一般にさらに難しい。

**実装候補**：PyMC / NumPyro / SciPy、階層効果（機種、受信機、飛行、場所）、Student-t雑音、混合分布による外れ値耐性。

**注意**：申告位置を真値として電力事前分布を学習すると、攻撃に汚染される。真距離ラベルのある管理下飛行を分離して校正する。

### 技術G：Kalman / EKF / UKF / Particle Filter / 状態空間

`a_t`にランダムウォーク、AR(1)、OU過程、スイッチングモデル等の**時間的な結びつき**を置く場合に使える。例えばOU的な相関を

```math
\rho(\Delta t)=\exp(-\Delta t/\tau)
```

と仮定し、`τ=10分`なら、1時間ギャップの相関は`e^{-6}≈0.0025`。**長時間の非同期観測が前後を結びつけるとは限らない**。反対に実機で長く安定した出力特性があれば、長期モデルの価値が高まる可能性がある。相関時間そのものを真値付きデータから推定しなければならない。

**比較**：一定P、ランダムウォークP、AR/OU、飛行ごとの段差、完全に独立P。「時間差1時間」「1日」での予測不確実性の増加を可視化。

### 技術H：Gaussian Process (GP) / 時変RSSマップ

```math
r_k=\mu_a-10n\log_{10}(d_k/d_0)+f_{\text{space}}(x_j,q_k)+f_{\text{time}}(t_k)+\eta_k
```

これは**申告位置が真と仮定した予測モデル**の例。観測が異時刻でも学習は可能だが、無制約Pと環境変化の寄与は識別できない。GPの予測分散は**定めたカーネル・雑音モデルのもとでの不確実性**であり、攻撃時の保証ではない。Santos et al.（2019）は時間変化するRSS場の再帰ベイズ/GPを研究し、送信電力・PLEにガウス事前分布を使っている。

**実装候補**：scikit-learn GP / GPyTorchの疎GP。入力は受信機位置、**申告**UAV位置、環境特徴、相対高度、時刻、機種、PHY。ラベルは観測RSSI。ただし実際の位置に誤差/偽装があると、モデルの対象は「申告値に条件づけられた観測」になり得る。

### 技術I：階層モデル＋変化点検出

BOCPD (Adams & MacKay, 2007) やCUSUMを用いて「申告位置に基づく必要電力」`a_required`の変化点を検出する。ただし検出されるのは、**申告座標・送信電力・伝搬条件・受信端末のいずれかによる変化**。それを「送信電力違反」と命名しない。

長期非同期では機体IDのなりすまし、飛行セッションの切れ目、受信機校正変更などが変化点に見える。機体／飛行／ノードごとにモデルを分割する。

## 4. Machine Learning / Physics-Informed / 外れ値検知

### 技術J：軽量回帰 — RF / XGBoost / MLP

入力：RSSI、受信機位置、端末種類、PHY、周辺環境、**申告**位置、飛行別の履歴統計。  
出力候補を明確に分ける：
- (J1) **RSSI予測**：申告位置等からRSSIの平均/分散を推定（観測不整合検知向き）。
- (J2) **距離回帰**：RSSIから距離を推定。**学習時に独立した真距離ラベルが必要**。
- (J3) **攻撃分類**：攻撃ラベルを与えて分類。未知の適応的攻撃への一般化は別途検証。

「学習が成功した」は原理的識別性の証拠ではない。データ分割は**同一飛行の隣接パケットが学習/テスト両方に入らない**よう飛行・日・機体・受信機別に行う。

### 技術K：LSTM / TCN / Transformer / small LM

**使いどころ**：短期で密な受信履歴からRSSIを次ステップ予測。  
**使えない条件**：毎回別の出力で、次の観測が1時間後、軌跡や実位置の真値もない場合に距離真値を一意に求めること。

Li, Liu & Yuen（2026）はQwen2.5小型モデルに物理的報酬を与えたRSSI復元を検証し、論文の主実験で`K=8`・`1秒間隔`、約2.85dBのRSSI予測MAEを報告。**UAVが固定基地局のビーコンを受信**し、送信電力・アンテナパターンは観測窓内一定。今回の敵対的RID**送信UAV**の距離推定精度として引用しない。

### 技術L：Physics-informed residual / 潜在混合モデル

単純物理式をまず適用し、残差だけをMLP/GPで学ぶ：

```math
r_{\mathrm{pred}}=\mu_a-10n\log_{10}(d_{\mathrm{claim}}/d_0)+f_\theta(\mathrm{environment},\mathrm{device},\mathrm{time}).
```

対象：信頼済み校正環境なら残差モデルの利点を測定できる。**申告位置が攻撃対象なら`d_claim`による条件付きの異常スコアであり、真位置の学習ではない**。

**必須の対照**：距離特徴を消したモデル、端末ID特徴を消したモデル、出力を独立ランダム化したモデル。ラベル漏洩・端末固有特徴の暗記を確認。

### 技術M：予測区間・Conformal Prediction

残差分布から予測区間・判定保留を導く。Conformalの標準的な有限サンプル包含保証は**校正/試験データの交換可能性など**が条件。時系列依存、飛行ごとの分布変化、攻撃者が分布を適応的に変えるケースで無条件に「95%保証」と言わない。

物理的な距離30mを含むかどうかと、**RSSI予測の区間包含**を混同しない。まず**RSSI**区間、真距離ラベルがある場合のみ**距離**区間を報告。

### 技術N：頑健推定・異常検出

Huber loss、Student-t、RANSAC、Mixture、CUSUM、BOCPD、GLRT、One-class classification、Isolation Forest。正常・位置偽装・出力変動・NLOSを含むデータで次を区別：
- N1：通常RSSIの外れ値（最も弱い主張）
- N2：申告軌跡を使った必要電力の異常（**原因非特定**）
- N3：独立真値と校正済みRF測定による送信出力操作の推定（観測条件の追加）

**敵対的評価が必要**：攻撃者が`a_k`を選べるなら、検知器の閾値や受信機の位置が分かっている/いない双方で最適化攻撃する。FPR一定条件（例1%、5%）のTPRとAUROC、保留率を報告する。

## 5. 受信メタデータ・追加の受信側情報

RSSI「以外」で使える情報はあるが、使えるからといって**真距離の独立測定**になるわけではない。

| 情報 | 取得主体 | 役割 | 注意 |
|---|---|---|---|
| Remote ID申告位置・速度・時刻 | ドローンが送信 | 内部整合性、残差の特徴 | **真実性は不信頼** |
| BLE RSSI | 受信機で測定 | 伝搬・残差推定 | 送信出力変化の影響 |
| 受信時刻 | 受信機で記録 | 順序・ギャップ・再送疑義 | 真の送信時刻/ToA距離ではない |
| PHY・広告情報・受信元アドレス | 受信機で記録 | 層別比較、機種差、偽装疑義 | ID固定性は保証されない |
| 送信側TxPowerフィールド（あれば） | ドローンの情報を受信 | 送信申告の追加特徴 | **物理的に検証したEIRPではない** |
| 受信/欠測/受信率 | 受信機で記録 | 電力・距離・感度の間接情報 | 発信窓/受信窓・閾値・PHYが必要 |
| チャネル別RSSI / 多アンテナ | 専用RX等 | 空間/周波数差分 | 実機APIで取得可否要確認、追加観測 |
| SDRのIQ/位相/ToA/DoA | 専用ハードウェア | より強い物理情報 | **RSSIだけの方式ではない** |

受信率・欠測は「電力未知でも絶対距離が得られる」魔法ではない。受信率のモデルには、送信回数、受信機スキャン窓、干渉、しきい値、出力が必要。**標準スマホAPIのみでIQ/方位/チャネル別独立RSSIが得られると仮定しない。**

## 6. 実験行列：何が分かれば方式を採用するか

### 6.1 シナリオを最低6群に分ける

| ID | 送信電力・申告の条件 | 真距離を推定できる期待 | 目的 |
|---|---|---|---|
| S0 | 既知・一定P、正常申告 | 校正すれば推定可能 | 物理モデル基準 |
| S1 | **未知だが一定P**、一部真値で校正 | 条件付きで可能 | パラメータ推定 |
| S2 | 未知P・**分布が安定**、正常な校正データ | **確率的**に可能 | Bayesian/GPの区間 |
| S3 | 飛行ごとに未知Pが変わり時間相関あり | 時間間隔次第 | Kalman/階層モデル |
| S4 | Pが大きく/急激に変化、OOD | 分布外では保証困難 | 異常と保留 |
| S5 | 位置偽装＋各フレームで敵対的P、1フレーム1RSSI | **一般に識別不能** | 不可能性の証明/反例 |
| S6 | S5だが同一イベントで複数RSSI | 条件付きで可能 | **別方式**としての対照 |

### 6.2 実験で固定するもの、変えるもの

- **固定**：乱数seed、伝搬モデル、受信機のGPS真値・較正、真の送信軌跡（合成の場合）、異なる受信機の時刻・セッション分離。
- **変化**：観測数10/100/500/1000/5000、時間差1s/10s/1h/1d、出力分布・電力相関時間`τ`、伝搬指数`n`、shadowing、端末オフセット、偽装距離・方向、偽装割合、未観測率。
- **同一の訓練分割**：normalのみの学習、飛行・日・場所・機体単位のテスト分離。合成真値とRF実測真値は別集計。
- **必須結果**：①RSSI MAE/RMSE ②真距離MAE/RMSE ③距離区間包含率/幅 ④送信電力変動*疑い*のAUROC・FPR/TPR ⑤誤原因帰属率 ⑥`UNDETERMINED`率 ⑦学習/推論コスト。
- **30m評価**：距離閾値付近（真距離20/25/29/30/31/35/40/50m）の区間判定を重点評価。申告位置とのずれ30mと安全離隔30mを混同しない。
- **失敗も結果**：S5で特徴量を増やしても同値反例を排除できない、S2で区間が広く30mを断定できない、S3で1時間の相関が消える等。

### 6.3 採用基準（性能値は実験前に決めない）

- **正当な主張**：明示した送信電力分布・真値・伝搬条件のもとで、別飛行において距離区間が設定した包含率に近く、正常電波を違反と誤認せず、保留を返せる。
- **不採用**：敵対的P・真位置不明で、物理的に距離を特定したと主張する。偽装と電力変動の原因を独立情報なしに断定する。
- **GATE-1**：S5の同値反例を1行の数式と再現コードで提示。
- **GATE-2**：S0–S4でベースライン、Bayesian、GP、MLPを比較し、誤差と不確実性を公正に評価。
- **GATE-3**：非同期・1時間/1日ギャップでの性能劣化を検証。
- **GATE-4**：結果の物理的意味が確認できてからZKP。

## 7. ZKP/Privacy：証明する演算の優先順位

物理の問題と暗号の問題を分割する。

| 段階 | 証明対象 | 最小回路の例 | 未保証 |
|---|---|---|---|
| Z0 | 機器ログのハッシュ/コミットメントとの整合 | Poseidon等の拘束 | そのログが真のRF観測か |
| Z1 | RSSIの校正、異常閾値判定、UNKNOWN分岐 | 固定小数点、範囲検査 | 真位置、出力操作の事実 |
| Z2 | 潜在電力の単純なフィルタ更新 | 固定された反復状態遷移 | 統計モデルの分布外妥当性 |
| Z3 | 小型MLPで固定した異常スコア | EZKL/ONNX、量子化比較 | NNの正解性/学習データ真正性 |
| Z4 | 非同期履歴の継続的検証 | 単一ノード内Nova、または個別証明検証 | 複数端末秘密Witnessの自動統合 |

**実装上の注意**：観測者A/B/Cが秘密RSSIを持つとき、横断統計量の秘密集約にはMPC、共同証明、公開可能な中間統計量等の明示したデータフローが必要。公開ID・時刻・判定履歴からの観測者の再識別も別評価する。**計算がZKで検証できても、入力信頼性は別の機構・信頼仮定。**

## 9. 次の研究提案（候補であり採択前）

**研究候補 R1：未知時変電力の条件付きRSSI距離推定＋不確実性校正**
- 新しい距離推定アルゴリズムが発明できたとは主張しない。先行Bayesian/GP/MLPを実データで比較し、時刻ギャップ・変動レベル・分布外条件による距離推定の**限界面**を描く。
- 秘密の観測位置とRSSIに基づく区間判定・保留をGroth16で証明し、Pi4/Pixel8上のコストを測定する。

**研究候補 R2：送信電力操作・位置申告異常の原因非識別性と、必要な最小の観測追加量**
- 1値/フレーム・非同期・自由Pのもとで原因が識別できないことを反例で示す。
- 出力分布の安定性、真距離アンカー、同一イベント複数RSSIなどを**一つずつ**足したとき何が初めて識別可能になるかを明示し、実RFの可否を追う。
- 単なる不可能性だけでなく、**いつ断定できず保留すべきか**の校正済み判定規則を確立する。

**採用するならまずR1/R2を比較。** 結果が出る前に「敵対的自由Pでも距離30mを絶対保証」「電力操作を確定検出」と題目にしない。

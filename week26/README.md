# Week26：RSSIの識別可能性と条件付き推定の評価

## 最新の結論と資料

**M1を追加した最新の観測条件評価**：[報告20：M0／M1／M2の同条件比較](20_M0_M1_M2_非同期RSSI位置偽装検知の観測条件評価.md)。20 seedを実行し、CSV／JSON／図9組を保存。M1は局所の同一送信・複数方向同時受信であり、局間の同時受信M2とは別。基本条件で横方向偽装には反応するが、同方向の距離偽装は残り、屋内BLE残差ストレスでは分離が弱い。実機の成立や実環境検知性能を確認したものではない。[更新する発表構成21](21_M0_M1_M2評価を中心とする発表構成.md)。既存PowerPointはM1追加前の資料として保持。

[3つの結果を条件から説明する24枚のスライドv4](slides/Week26_3つの結果_条件と追加比較_v4.pptx)／[追加シミュレーション・グラフ・再現手順19](19_3つの結論を説明する追加シミュレーション.md)。

元の「別送信を1台ずつ観測し、各送信の電力が自由」という条件で、位置偽装の一般的な識別を実現した段階ではない。位置のみの改変では正常との差が小さく、電力も変更すると共通標本で警報を正常付近へ戻せた。同一送信の5台受信は、元の条件へ観測を追加する別構成として評価した。数値は合成であり、実RIDの攻撃実証ではない。

## 保証と残件

- 識別不能性は、各イベントで電力を自由に選べるモデルの結論。機器が現実に必要出力を設定できるかは別検証。
- BLEの公開実測は屋内固定ビーコン。実UAV Remote ID、Pi／Pixelの新規RF実測ではない。
- 校正分布内での推定精度と、敵対的分布外での物理距離保証を区別。
- Week26の新しいZKP回路、Pi／Pixel実測、TEE／TPM導入はこれらの文書では未実施。

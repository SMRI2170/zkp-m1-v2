# LoRaIQのIQメタデータ監査と観測量の採用判断

2026-11-03〜04に実行。[前回のCSV監査](06_UAV送信データの取得監査と条件単位の不確実性評価.md)に続き、実SigMFメタデータ24件を取得し、校正の成立条件を確認した。

**結論：調べた24件では、IQ形式は確定できたが、dBm RSSIへの校正は成立していない。現在使える実測量はCSVのSNRであり、相対IQ電力はIQ本体取得後に別途定義・評価する候補。** 未確認のゲイン・AGC・雑音床・高度を仮定して、位置偽装の検出率を追加していない。

## 1. 実際に取得したものと範囲

[LoRaIQ v2、Zenodo 20341802](https://zenodo.org/records/20341802)の`sigmfs.zip`は71,002,741,525 bytes。HTTP Rangeが206と正しいContent-Rangeを返すことを確認し、ZIP索引と選択メンバーに必要な範囲だけ取得した。

| 項目 | 結果 |
|---|---|
| 選択方法 | ハッシュ固定CSVを順に読み、各UAVセッション・各受信局の最初の位置付き行が指すメタデータを選択 |
| 選択ファイル | 6セッション×4局＝24件 |
| 重複を除く取得範囲サイズ | 26,971,084 bytes：約25.72MiB |
| 展開したメタデータ本文 | 合計61,102 bytes |
| IQ本体の取得・解析 | **未実施** |
| 全ZIPのMD5検証 | **未実施**：部分取得なので照合できない |
| 部分取得の整合確認 | 範囲長・Content-Range、展開メンバーCRC32、取得範囲と本文のSHA-256 |

取得範囲サイズは完了した取得manifestのユニーク範囲の合計。最初の索引読み込み試行で保存した未使用断片や再取得を含む総ネットワーク転送量ではない。メンバーCRC32はZIP内の整合検査であり、独立した真正性証明ではない。

**24件は各セッションの代表標本であり、全ファイル・全時間帯を網羅しない。** 同じファイルに複数フレーム注釈がある場合もあり、24独立送信の測定とはしない。受信局ごとの最初の位置付き行は同一送信とは限らず、今回の標本間で多局電力差を計算していない。

元のメタデータには座標・時刻・ペイロードが含まれるため、`captures/week27-loraiq-iq-metadata/`にのみ保存。ディレクトリ0700、ファイル0600。Gitにはキー名、形式、件数、ハッシュと採用判断だけを保存する。

| 振幅の基準・スケーリング | 校正値を確認できず | 保存値からdBmや正式なdBFSを直ちに断定できない |
| USRP受信ゲイン | 該当フィールドを確認できず | 局間差・時間変化を補正できていない |
| AGC | 設定を確認できず | 固定ゲイン／AGC無効とは仮定しない |
| 雑音床・ノイズ校正 | 絶対雑音電力を確認できず | SNRからdBmへ換算できていない |
| アンテナ利得・ケーブル損失 | 校正情報を確認できず | 局間受信系統差の既知補正は未成立 |

欠けているのは**調べた24件とCSVにおける情報**。公開データ全体に絶対に存在しないとは断定しない。コメント内のタブ区切り項目も調べたが、SNR・平面座標・速度等の注釈で、上記校正情報は確認できなかった。

SigMFの型定義におけるbit幅はI/Q各成分の幅。[SigMF公式仕様](https://sigmf.org/)を参照。また、UHD公式資料はdBFSとdBmの対応に受信電力基準・校正が必要と説明している。これは一般的な必要条件であり、このUSRP-2920記録に校正済み電力APIが利用されていたことの証拠ではない。[UHD Power Level Controls](https://files.ettus.com/manual/page_power.html)

Tapparel・Burg, *Dataset and UAV Propagation Channel Modeling for LoRa in the 860 MHz ISM Band*, arXiv:2512.15268v1（2025）。[原論文PDF](https://arxiv.org/pdf/2512.15268)

- §III-B：UAV搭載GPSから得た位置・速度を送信ペイロードに含める構成。配布位置は、攻撃機体から独立した真値計測として認証されたものではない。

原論文はv1、今回取得したデータはv2。原論文の図表・件数をv2で追試したとは主張しない。本文で使う受信機高さの代表値も、欠けたUAV高度時系列の代用にはしない。

## 4. 観測量ごとの採否

### 校正dBm RSSI：保留

形式とサンプルレートだけでは受信電力を校正できない。受信ゲインが分かっても、基準電力、周波数依存、受信系統の差が未確認ならdBmへの変換は保証できない。現在のRSSI検出器との同条件比較は継続保留。

### 相対IQ電力：定義できる候補、未計測

保存IQをx[k]=I[k]+jQ[k]として、フレーム区間の

```text
Q_on = mean(I[k]^2 + Q[k]^2)
Y = 10 log10(Q_on)
```

は計算できる。ただしYは**保存振幅単位を基準とする対数エネルギー**であり、今回dBm・dBFSという校正済み単位を与えない。またQ_onには雑音・干渉が含まれ、信号だけの電力ではない。雑音区間を使って線形領域で`Q_signal = Q_on − Q_noise`を推定する場合も、区間の妥当性、雑音の変動、AGC、飽和を確認する必要がある。非正値を黙って小さな値に置換しない。

局間差を使うには、局ごとの振幅基準が時間的に安定するか、正常学習データで相対偏差を推定できるかを別に検証する。現在はその安定性も未確認。

### SNR：取得済み、追加仮定を明示した別評価候補

理想的な定義では、受信信号電力R_i、雑音床N_iをdBmで表すと、

```text
SNR_i = R_i − N_i
SNR_i − SNR_j
  = −(L_i − L_j) + (b_i − b_j) − (N_i − N_j) + 誤差
```

同一送信の共通電力は消えるが、雑音床の局間差・時間変化と受信系統偏差は残る。さらに実際のCSV値は推定SNRなので、推定方法や低SNR時のバイアスも確認対象となる。「SNR差分なら無校正で位置を検証できる」とは結論しない。

**今後はSNRをSNRとして定義した別実験**に進める可能性がある。条件は、正常データと評価データの分離、局ごとの偏差の扱い、未知高度を含む距離の定義、雑音変動への感度評価を先に定めること。

## 5. 研究設計の判断

| 分岐 | 今回の判定 | 次に必要なこと |
|---|---|---|
| 絶対電力の校正情報が揃う | 未成立 | 受信設定・校正・受信系統の公開情報を追加確認 |
| 相対IQ電力を用いる | 候補 | 同一送信のIQを少数取得し、振幅基準・飽和・雑音区間・局差を検査 |
| CSVのSNRを用いる | 候補 | SNR推定法と局別雑音・偏差をモデル化し、SNR検査として評価 |
| 本来の非同期・別送信条件を解決したか | **未解決** | 同一送信の多局観測は追加条件の比較対照として扱う |

今回確定したのは、校正情報が不足している場所と、次の観測量を選ぶための条件。位置偽装検出率、AoA精度、物理的な電力変更時の受信欠落、独立した真位置証明は追加実証していない。

# RSSI でどう計算して詐称を見抜くか（説明用）

目的: 「電波強度(RSSI)から距離 → 複数端末から位置 → 放送位置と照合して詐称判定」という
**計算の中身**を、具体的な数値付きで追えるようにまとめたもの。教授への口頭説明用。

---

## 0. 全体像（1行）

各端末は「放送された位置から計算した距離」と「電波強度から測った距離」の**2つを持つ**。
本物なら一致し、位置を詐称すると食い違う。複数端末の距離を連立すれば**発信源の位置そのもの**も割り出せる。

```
   放送位置 ──幾何計算──▶ d_claim ┐
                                   ├─ 一致すれば本物 / ずれれば詐称
   電波強度 ──物理モデル─▶ d_meas ┘
```

---

## 1. ステップ1：電波強度 RSSI から距離を出す

電波は距離が伸びるほど弱くなる。この減り方を対数の式で表すのが **log-distance path loss モデル**:

```
RSSI(d) = A − 10·n·log10(d)
```

- `A` … 1m 離れたときの受信強度[dBm]（機体・環境で決まる定数）
- `n` … 減衰の速さ（自由空間=2.0、市街地=2.5〜4）

これを距離について解くと、受信した RSSI から距離を推定できる:

```
d_meas = 10^((A − RSSI) / (10·n))
```

**具体例**（A = −40 dBm, n = 2.5 とする）
- 距離 30m の電波: RSSI = −40 − 25·log10(30) = −40 − 25·1.477 = **−76.9 dBm**
- 逆に −76.9 dBm を受けたら: d = 10^((−40 −(−76.9)) / 25) = 10^(36.9/25) = 10^1.477 = **30m**

→ 「電波強度を測る = 距離を測る」ことになる。`A` と `n` は実機 DJI で（距離, RSSI）を数十点
とって直線当てはめ（最小二乗）すれば決まる。

---

## 2. ステップ2：1台での「整合しているか」の計算

その端末は、放送された位置と自分の GPS から**幾何的な距離** `d_claim` も計算できる（ただの2点間距離）。
本物なら `d_claim ≈ d_meas`。ここで **単純な引き算で比べてはいけない**理由がある。

### なぜ「比（log）」で比べるのか
RSSI の測定誤差 σ[dB] は、距離では**掛け算的（相対的）**に効く。
たとえば同じ ±4dB の誤差でも、近距離では ±数十cm、遠距離では ±数mになる。
だから「±3m以内なら一致」のような固定幅ではなく、**「何倍ずれたか」= 比**で見るのが正しい:

```
ずれ具合 = | log10(d_claim / d_meas) |
整合とみなす ⇔ ずれ具合 ≤ τ     （τ = k·σ / (10n)、k=2 で約2σぶんの許容）
```

**具体例**（σ = 4dB → τ = 2·4/25 = 0.32）
- 本物: d_claim = 30m, d_meas = 27.5m → |log10(30/27.5)| = 0.038 ≤ 0.32 → **整合(OK)**
- 詐称: 攻撃者が「5m先にいる」と放送。でも実際は30m先 → d_claim = 5m, d_meas = 30m
  → |log10(5/30)| = 0.778 > 0.32 → **矛盾(suspicious)**

→ 位置を書き換えると幾何距離だけが変わり、電波が示す距離と食い違うので**バレる**。

---

## 3. ステップ3：単発だと粗いので「中央値」でならす

1回の RSSI はマルチパス（反射）で暴れる。そこで同じ機体の RSSI を短時間に M 回集め、
**中央値**をとってから距離に直す。中央値は外れ値に強く、実質的な誤差 σ を小さくできる。
（M=5〜10 程度。平均でなく中央値なのは、大きな反射の外れ値1つで平均が引きずられるのを避けるため。）

---

## 4. ステップ4：複数端末で「発信源の位置そのもの」を割り出す（核心）

1台だと「距離」しか分からない（発信源はその端末を中心とする円のどこか）。
**場所の違う N 台**の距離を連立すると、円が交わる1点＝発信源の位置が出る。これが多辺測量。

### 計算の中身
各端末の位置 `W_i = (x_i, y_i, 0)`（地上, z=0）、その端末が測った距離 `d_i`、
求めたい発信源を `P = (x, y, h)` とすると、各端末について:

```
d_i² = (x − x_i)² + (y − y_i)² + h²        … (円/球の式)
```

この式は x², y², h² が入っていて非線形。そこで**1本目(i=0)を全部から引く**と、
x²・y²・**h² が消えて**、x と y の1次式（直線の式）になる:

```
d_i² − d_0² = (x_i²+y_i² − x_0²−y_0²) − 2·[ x(x_i−x_0) + y(y_i−y_0) ]
```

これを i=1,2,…,N−1 について並べれば、未知数 (x, y) の連立1次方程式。
端末が3台以上あれば**最小二乗で (x,y) が解ける**（高さ h は引き算で消えたので水平位置だけ求まる）。

### 手で解ける具体例（3台）
発信源が原点 (0,0) にあり、端末が
`W0=(40,0)`, `W1=(0,40)`, `W2=(−40,0)`。3台とも距離 40m を測ったとする。

- i=1 の式: d1²−d0² = 0。右辺 = (0+1600−1600−0) − 2[x(0−40)+y(40−0)] = 80x − 80y
  → 0 = 80x − 80y → **x = y**
- i=2 の式: d2²−d0² = 0。右辺 = (1600−1600) − 2[x(−40−40)+y·0] = 160x
  → 0 = 160x → **x = 0**、よって y = 0

→ 解 (x,y) = **(0,0)**。3台の距離だけから発信源の位置を復元できた。
（実際は RSSI にノイズが乗るので円はぴったり交わらない。だから「最小二乗＝一番もっともらしい交点」を選ぶ。）

---

## 5. ステップ5：割り出した位置と放送位置を照合して詐称判定

ステップ4で得た**推定発信源 P_hat** と、放送された位置 **P_claim** の距離（残差）を見る:

```
residual = ‖ P_hat − P_claim ‖（水平）
residual > 閾値  ⇒  位置詐称
```

**直感**: 放送位置は1点だが端末は空間に散らばっている。攻撃者が位置を偽っても、
真の発信源の近くにいる端末は必ず矛盾を出すので、**全端末の幾何を同時に満たす偽装は作れない**。

---

## 6. ステップ6：1台の判定を「多数決」でまとめる

最終判定は、各端末が出した整合/矛盾を**チェーン上で数える**だけ:

```
整合と言った端末が K 台以上 → 放送を信頼 (trusted)
矛盾と言った端末が K 台以上 → なりすまし警報 (spoofAlert)
```

「同じ機体・同じ時間窓」の端末だけを束ねる（time_bucket で対応付け）。
なお、各端末は座標や生 RSSI を明かさず「整合したか(1/0)」だけをゼロ知識証明で出すので、
**位置プライバシーを守ったまま**多数決できる。

---

## 7. 計算の流れ（まとめ）

```
① 電波強度 RSSI ──[ d = 10^((A−RSSI)/10n) ]──▶ 距離 d_meas
② 放送位置＋自GPS ──[ 2点間距離 ]──▶ 距離 d_claim
③ |log10(d_claim/d_meas)| ≤ τ ? ──▶ この端末は整合/矛盾（1台の判定）
④ 複数端末の (位置, d_meas) を連立 ──▶ 発信源の位置 P_hat（多辺測量）
⑤ ‖P_hat − P_claim‖ > 閾値 ? ──▶ 位置詐称の判定（位置ベース）
⑥ 整合/矛盾を K 台で多数決 ──▶ trusted / spoofAlert
```

- ③ が「1台版」、④⑤ が「位置を実際に割り出す版」、⑥ が「みんなでまとめる」段。
- 評価では ③の多数決 と ⑤の位置推定 を比べ、**現実のノイズでは③の多数決が強い**という結果
  （精密に位置を解こうとすると、ノイズで解が暴れて逆に不利）。だから実装の既定は③、⑤は補助。

---

## 8. 教授に一言でいうなら

> 「電波の強さは距離の対数で決まる、という物理モデルを逆に使って距離を測ります。
>  放送された位置から幾何的に出した距離と、電波から測った距離を**比で**照合し、食い違えば詐称。
>  さらに場所の違う複数端末の距離を連立すれば、発信源の位置そのものを最小二乗で復元できます。
>  最後はその判定を複数端末の多数決でまとめ、各端末は結果だけをゼロ知識証明で出すので
>  位置を明かさずに合意できます。」

# Week25：非同時・長期Remote ID観測と未知送信電力：研究議論の整理

**作成日：2026-10-19**  
**状態：研究構想・数理的検討。検出率・精度・実機結果は未測定であり、実証済みとは主張しない。**  
関連：[Week25 Issue #66](https://github.com/SMRI2170/zkp-m1-v2/issues/66)、[物理判定 #17](https://github.com/SMRI2170/zkp-m1-v2/issues/17)、[Mode C #26](https://github.com/SMRI2170/zkp-m1-v2/issues/26)、[攻撃実験 #36](https://github.com/SMRI2170/zkp-m1-v2/issues/36)

## 1. この研究の本当の想定シナリオ

- 異なる場所の複数の受信ノードが、**同じRemote IDを名乗るUAV**を長期にわたり観測する。
- ノードAが10:00、ノードBが11:00、ノードCが翌日、というように**1時間・1日以上離れた、異なるフレーム**でよい。同時・同一フレーム観測は要求しない。
- 累積数は**1000回以上**を想定し、10・100・500・1000・5000回を比較対象とする。
- 受信ノードの位置・時刻・RSSIは信頼できる、または改ざん検知が可能であると仮定する。この前提が実機で達成されたとはまだ主張しない。
- **機体が送信する位置、送信電力、IDの真実性は信頼しない**。
- 最終目的は、ドローン運航事業者・空港・行政が利用可能な、長期に蓄積したRemote IDの**監査可能な観測証拠・運航リスク評価**を研究すること。
- 「同じRemote ID文字列」＝「同じ物理機体」とは限らない。機体IDの暗号認証・なりすましと事業者への帰属を分離する。

### 教授の問い

「RSSIから距離を測るとき、送信電力が未知、または偽られている場合でも位置情報を検証できるのか。単一ノードと複数ノードでは何が解決するのか」

今回の研究では、さらに次を問う。

1. 数時間・数日離れた1000件の観測で、送信電力と真の位置を識別できる条件は何か。
2. 送信電力に時間的・統計的な規則性があるなら、長期蓄積によって位置偽装の疑いを推定できるか。
3. 攻撃者が毎回自由に出力を調整できる場合、どの追加証拠が必要か。
4. 結果をZKPによりプライバシーを保護しつつ監査可能にするには何が必要か。

## 2. 電波フレーム・同時観測との違い

Wi-Fi Beaconの**1フレーム**は1回の送信イベントであり、送信時間は条件により通常数百µs〜数ms程度。「同じUAVが異なる時刻に出した同内容のパケット」は別フレーム。

**同一フレーム・同時観測のRSSI差分（DRSS）**：
- 共通の送信電力と較正済み受信機・伝搬モデルを仮定すると、複数受信機のRSSI差から未知の送信電力成分を相殺し、距離比・申告位置整合を調べられる。
- この方式は、3Dの真位置・30m安全距離の保証ではない。受信配置、モデル誤差、なりすまし等の限界がある。

**本研究の主対象である非同時観測**：
- 1時間後の別フレームで出力が同じとは限らず、UAVも移動している。
- 時間差が1時間だから不可能というわけではない。**時間を跨いで共通に成立する送信条件・軌道・証拠がない場合に、RSSI差分だけでは不可能**なのが本質。
- [#26](https://github.com/SMRI2170/zkp-m1-v2/issues/26) は「同一時間窓内で別フレームを許す」プロトコルであり、1日離れた長期履歴を同一セッションに混ぜる設計ではない。

## 3. 数式：信頼できる1000回のRSSIで何が分かるか

観測k（ノードj(k)、時刻t_k）の簡略対数距離モデル：

\[
R_k=A_k+b_{j(k)}-10n_k\log_{10}\left(\frac{\|x(t_k)-a_{j(k)}\|}{d_0}\right)+\epsilon_k
\]

- R_k：受信RSSI（信頼できる測定値）[dBm]
- A_k：未知の実効基準受信電力（送信電力・アンテナ利得・基準距離損失を含む）
- b_j：受信機ごとの較正偏差
- n_k：伝搬指数（環境・経路で異なり得る）
- x(t_k)：UAVの**実位置（未知）**
- a_j：受信機位置（既知）
- ε_k：遮蔽、マルチパス、測定・モデル誤差
- d0：基準距離

### 3.1 毎回の送信電力が未知かつ無制約で変わる場合

仮に伝搬指数や受信機偏差が完全に既知でも、任意の候補の実位置軌跡 x̃(t_k) に対し、

\[
\widetilde A_k=
R_k-b_{j(k)}
+10n\log_{10}\left(\frac{\|\widetilde x(t_k)-a_{j(k)}\|}{d_0}\right)
-\epsilon_k
\]

という送信条件を選べば、同じRSSI履歴が得られる。

**したがって、各時刻の送信電力が自由・無制約に変わり、独立した位置拘束も無いなら、1000回でも真位置・位置偽装は一般に識別不能。**

ここで受信ノードが正直であることは「RSSIが記録どおり」を保証するだけで、未知の発信距離と送信出力の組を一意に決めるものではない。

単純な例：経路損失指数n=2なら、送信距離を10倍に変えて送信電力を20dB強くすることにより、理想モデル上は同じRSSIを作れる。逆に近い位置から20dB弱く送ることもできる。これは攻撃者が実際にその出力幅を持てることを保証する例ではなく、**未知量の識別不能性を示す理想化例**である。

### 3.2 何を仮定すれば1000回の累積が有効か

| 送信電力の仮定 | 累積から推定可能なもの | 注意点 |
|---|---|---|
| 長期にほぼ一定（絶対値だけ未知） | 送信特性の推定、申告位置からの逆算値の外れ値 | 多くの申告位置が正しい・伝搬モデルが較正済み等のアンカーが必要 |
| 飛行ごとに変わるが分布が安定 | 機体・飛行単位の階層的な分布、異常疑義 | 申告の偽装混入・季節・地形・機種の影響 |
| 時間的な変化率に上限がある | カルマンフィルタ等の時系列追跡 | 1時間/1日の空白で不確実性が増える |
| 出力に既知の物理的上下限がある | 距離の可能区間や明らかな矛盾 | 伝搬とアンテナ方向を含む誤差境界が必要 |
| 各時刻に任意・無制約に変更可能 | RSSIのみでは真位置の一意復元・確実な偽装検知不可 | 観測件数を増やすだけでは解決しない |
| 別センサーでその時点の独立した距離・位置証拠がある | その観測時点の申告位置と物理位置の矛盾を検査可能 | 証拠の較正、真正性と未観測時刻を別管理 |

### 3.3 「申告位置が正しいと仮定した場合の送信電力」を逆算して1000回蓄積

申告位置x_claim,kと受信ノード位置から、申告距離d_claim,kを求める。

\[
\widehat A_k=
R_k-b_{j(k)}+10n\log_{10}\left(\frac{d_{\mathrm{claim},k}}{d_0}\right)
\]

**Â_k は送信電力の直接測定値ではなく、申告位置が正しいと仮定したとき必要な実効基準受信電力**である。

これを1000件蓄積し、中央値・分散・飛行別の階層モデル・時間モデルから外れた値を「位置偽装**または送信条件/伝搬環境の変化**の疑い」と扱う。

申告位置が一貫していても真実とは限らない。攻撃者が放送位置に合わせて送信電力を調整したり、最初の学習期間から偽装データを混ぜたりすれば、正常に見える分布を形成できる可能性がある。

## 4. 送信電力を変えられるのか／RSSIは一定か

- 技術的には送信出力を設定・変更できる無線送信機が存在する（対応チップ・ドライバ・規制条件に依存）。
- **研究室のDJI Matrice 350 RTKにおけるRemote ID送信出力が毎フレーム変わるという事実は未確認**。実測や機器仕様の検証が必要。
- 送信電力が固定でも、姿勢、アンテナ指向性、遮蔽、反射、受信機個体差によりRSSIは変動する。
- 「未知だが一定」と「未知でゆっくり変化」と「攻撃者が毎回自由に変更可能」は、異なる脅威モデルとして実験する。
- 実際の送信電力そのものはRSSIだけでは確認できない。送信機の出力ログ等の信頼性や、校正済みRF測定が別途必要。

## 5. 長期履歴で検出できる異常／できない保証

| 確認事項 | 判定の可能性 |
|---|---|
| 申告位置と、学習したRSSI特性の統計的な不一致 | 条件付きで検出可能。位置偽装の**確定**ではない |
| 申告軌跡にあり得ない速度ジャンプ | 速度上限を前提に**申告データの矛盾**を検出可能 |
| 同一観測時点のレーダー等による物理位置とRID位置の不一致 | 測定誤差を評価して検出可能 |
| 1時間〜1日の未観測時間の正確な軌跡 | 一般に不明。過去と未来の2点だけで途中を保証しない |
| 複製したRemote IDを別機体が送信 | RID文字列の一致だけでは検出・帰属できない。暗号学的なID認証が別途必要 |
| 過去の受信証拠が改ざんされた | ノード署名・ハッシュ・コミットメント等により検出可能 |
| 30m離隔を満たしていたか | 対象時刻の独立した位置・距離区間がなければ **UNKNOWN** |
| 長期統計スコアから正規事業者の違反を確定 | 不適切。偽装ID・機体帰属・物理真値を別々に審査する |

**信頼度の蓄積単位**：「申告されたRID文字列」「暗号学的に認証した機体」「飛行セッション」「運航者・事業者」を分離する。不正者が正規機体のIDをコピーして正規事業者の評判を落とす攻撃も試験対象とする。

## 6. 空港・行政・運航事業者向けの構成案

1. **OBSERVE**：Pi 4×2、Pixel 8等が、RID payload、RSSI、受信時刻、ノード位置、PHY、チャネル、測定品質、較正版を記録。
2. **ATTEST**：ノード認証・署名・観測コミットメントで改ざん検知可能なイベントにする。
3. **ID CHECK**：申告IDと認証可能な機体IDを区別。再送/なりすましも別警告。
4. **LOCAL CHECK**：各観測時点の物理判定、品質、時間整合を算出。情報不足はUNDETERMINED。
5. **HISTORY**：1時間・1日以上離れた証拠を機体・飛行別に蓄積し、固定・階層・逐次の統計モデルを比較する。
6. **ZKP / AUDIT**：秘密観測に対して、定めた判定・統計更新を正しく計算したことを証明。
7. **RISK / REVIEW**：本人確認、位置不整合疑義、許可・運航整合、ZKP有効性を**別々の状態**として提示。機体や事業者の責任をスコアだけで自動確定しない。

### 推奨する長期データモデル

- observationId / nodeId / receiverKeyId / receivedAt / clockAccuracy
- receiverPositionCommitment / receiverAccuracy / calibrationVersion
- phy / channel / RSSI / rawPacketDigest / measurementQuality
- claimedRid / ridPayloadCommitment / ridAuthStatus / claimedPosition / claimedTime
- authenticatedAirframeId（取得できた場合のみ） / flightId（関連付けできた場合のみ）
- localVerdict / longitudinalVerdict / confidenceInterval / reasonCodes
- policyHash / modelVersion / proofDigest / nodeSignature

これらを全て公開すべきという意味ではない。受信位置・時間・RIDの組み合わせによる追跡リスクを検討し、必要なものだけ公開する。

### ZKPの保証範囲

**できること**：秘密観測値とコミットメントの一致、指定されたルールに従う判定計算、履歴更新の正当性の証明（実装されたプロトコルの範囲）。

**できないこと**：RSSIから真の位置が必ず判明すること、センサー値が物理的に真実であること、ID文字列が正規機体を指すこと、未観測の1時間が安全だったことの証明。

複数ノードの独立ZKPを単純に多数決しても、秘密RSSIにまたがる統計量は自動で計算されない。秘密共有、MPC、安全な集約、あるいは許容できる公開統計量の追加設計が必要。Besu等のオンチェーン記録を導入しても、RF物理データの真実性は改善しない。

## 7. Week25に実施する比較実験

**主題**：長期・非同時・1000件以上のRemote ID観測が、未知送信電力下の位置偽装疑義の検出にどの程度役立つか。

| 比較軸 | 実験条件 |
|---|---|
| 観測数 | 10 / 100 / 500 / 1000 / 5000 |
| 観測間隔 | 10秒（対照） / 1時間 / 1日 |
| ノード数 | 1 / 2 / 3（4以上は追加シミュレーション） |
| 送信電力 | 一定未知 / 飛行ごと可変 / 緩やかに変化 / 各観測で独立 / 偽装位置に適応的 |
| 位置申告 | 正常 / 一部偽装 / 常時偽装 / 不可能速度の自己矛盾 |
| 受信条件 | 較正済み / 受信機偏差 / n変化 / 指向性 / マルチパス / 欠測 |
| 独立真値 | なし / 一部の飛行で別センサー等により確認可能 |
| IDの攻撃 | コピーID・再送・認証なし・認証成功 |

**比較する手法**：
1. 従来の固定送信電力を仮定した単発RSSI距離推定（限界を示すベースライン）。
2. 申告距離から逆算した必要送信電力Âの頑健な中央値・ばらつき・外れ値検知。
3. カルマンフィルタ等の状態空間モデル（時間変化を仮定）。
4. 機体・飛行・受信機別の階層的な統計モデル。
5. RID申告位置の速度・時刻整合ルール（RSSI不使用の対照）。
6. 一部の観測に独立物理真値がある場合の判定（追加条件の効果）。

**評価指標**：真陽性率(TPR)、偽陽性率(FPR)、判断不能率、信頼区間、学習量依存性、長時間ギャップでの精度低下、異なるノード・日・場所・機体への一般化、コピーIDによる誤帰属。学習/評価は飛行・日付・機体を適切に分離し、過去の偽装データによる学習汚染を試験する。

**必ず入れる反例・否定テスト**：
- 送信出力が無制約なら、真位置と偽位置が全く同じ1000件のRSSI履歴を生み得る。
- 固定出力・誤差小ならÂの分布は集中する。
- 非偽装でも遮蔽・姿勢・受信機個体差でÂの外れ値が発生する。
- なりすましIDを正規機体・事業者に自動帰属させない。
- 30m距離を直接確認できないケースはUNKNOWNとする。

## 10. 教授向けの暫定結論とWeek25 Done

> 1時間・1日離れて収集した1000件以上の信頼できるRemote ID・RSSI観測は、機体ごとの送信特性や申告位置との統計的な不整合を学習し、運航のリスクを監査する証拠として利用できる可能性がある。一方、各送信の出力が任意に変化でき、独立の距離・位置拘束が無い場合、RSSIのみでは実位置を識別できない。この限界を理論的に示し、固定・時変・適応的送信出力条件で検出率と誤警報率を比較する。ZKPは秘匿観測に対する計算と履歴整合の保証を担い、RF物理真実や運航上の安全の保証とは分離する。

- [ ] 非同時・1000件の脅威モデルと無制約出力下の非識別性を式で示す。
- [ ] 固定・飛行単位変動・緩変動・適応的攻撃を合成/replayで比較する。
- [ ] 10〜5000件、1時間/1日間隔による検出率・誤警報率・UNKNOWN率を計測する。
- [ ] RID文字列と認証済み機体ID・運航者の帰属を分離する。
- [ ] ZKPの計算保証と物理的な位置検証の差を明示する。

**一行要約：1000件の累積は有用になり得るが、解けるかどうかを決めるのは件数ではなく、時刻間で共有する送信特性の拘束・較正・独立物理証拠と攻撃者モデルである。**

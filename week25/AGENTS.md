# Week25の調査資料の管理

ユーザー指定：MiniMaxの調査は別ディレクトリに置き、主担当が整理した資料だけを作成・更新する。

- MiniMax / mcodeの報告は `week25/minimax/reports/` に保存する。統合担当の出力も未検証のエージェント報告として扱う。
- エージェントが収集した文献台帳は `week25/minimax/manifests/`、実行計画・過去の稼働記録は `week25/minimax/operations/` に保存する。
- 実行ログ・途中ノート・取得した論文本文は引き続きignored `.cache/week25/` に保存する。秘密情報やフィールドデータをGitへ追加しない。
- MiniMaxには `week25` 直下の文書、主担当の整理資料、既存の実装を編集させない。指示には担当ごとの出力先とこの境界を明記する。
- 主担当が原典、前提、計算、矛盾を確認し、採用できる内容と未確認を区別して `week25` 直下の整理資料を更新する。
- MiniMaxの終了コード0、エージェント間の一致、統合レポートの出力は、原典確認・実機検証・研究要件の成立を意味しない。
- 生の報告を移動したらリンクと出力設定を更新する。古いイベントログ・プロンプトは実行当時の記録として保持し、訂正と混同しない。
- この規約は追加のエージェント起動や実機作業を自動的に許可するものではない。現在のユーザー指示の範囲で進める。

リポジトリルートのAGENTS.mdにある研究PoCの境界とデータ管理規則も適用する。

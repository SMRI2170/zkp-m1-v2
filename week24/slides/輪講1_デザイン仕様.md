# 「輪講1.pptx」のデザイン仕様・観察記録

## 1. この記録の対象

対象は同じディレクトリの[輪講1.pptx](輪講1.pptx)。研究内容、論文の説明、章の並び方、実験結果の解釈はこの記録の対象にしない。別の内容で同じ見せ方を再現するため、配置・文字組み・段落階層・色・図表の扱いを記録する。

全34枚を画像化し、全スライドのXMLから文字・色・段落設定を確認した。目視による詳細確認は1、4、8、10、26、28、30、33枚目を中心に実施した。以下で「実測」はPPTX内部の設定値、「観察」は画像上の見え方、「適用時の扱い」は新しい資料を作る際の判断を表す。元のファイルは変更していない。

## 5. 小見出し・本文・補足のインデント

### 見た目の階層

```text
■ 小見出し                           ← 青・太字、本文枠の左端
• 本文の説明                         ← 黒、本文開始位置を少し下げる
  本文が折り返した行                 ← 「•」ではなく本文の字頭に揃える
    • 直前の本文に属する補足          ← さらに右へ字下げ
      補足の折り返し                 ← 補足本文の字頭に揃える

■ 次の小見出し                       ← 左端へ戻して新しいまとまりを開始
• 本文の説明
```

### PPTXの段落設定から確認できた値

本文枠内を基準とした値。`marL` は本文の左マージン、`indent` は最初の行のぶら下げ量。

| 階層 | 左マージン `marL` | ぶら下げ `indent` | 本文開始の相対位置 | 箇条書き記号の相対位置 |
|---|---:|---:|---:|---:|
| 小見出し | 0 | 0 | 0 | 「■」を文字として置く |
| 通常の箇条書き | 285,750 EMU | −285,750 EMU | 約0.794 cm | 約0 cm |
| 一段下の補足 | 742,950 EMU | −285,750 EMU | 約2.064 cm | 約1.270 cm |

補足には `lvl=1` が指定される。親の本文から補足本文への字下げ差は約1.27 cm。通常の箇条書き172段落、同設定の補足40段落がXMLで確認できた。

通常本文・補足とも、箇条書き記号は `•`。この記号のフォントにはArialが指定されている。本文の日本語書体とは別設定になっている。

### 折り返しと改行

- 箇条書きの2行目は、本文の始まりに揃える「ぶら下げインデント」を使用。
- 説明を一段詳しくするときに段落レベルを下げる。単に行を増やしただけの続きは、同じ段落内の改行として扱う例もある。
- 括弧の補足や短い関係表現は本文に続ける例がある。
- 新しい小見出しでは、補足の字下げ位置を引き継がず、本文枠の左端へ戻る。
- スペース文字を何個も打つだけの見た目合わせではなく、段落属性で階層を設定する。

通常箇条書き・補足では段落前3 ptが設定された例を確認した。行間はテーマ・既定値・個別設定の影響があり、この記録では全ページ共通の固定行間とは断定しない。

## 6. 文のまとめ方・強調範囲

ここでは文章の内容ではなく、文字の組み方だけを記録する。

1. **青い小見出しでひとまとまりを開始する。** その下に黒い本文を置く。
2. **本文と補足を字下げで分ける。** 同じ強さの文章をすべて同じ左端に並べない。
3. **一文の中の一部だけを強調する。** 文頭から文末までを一律に青や赤にするより、語句・数値・短い節を太字と色で目立たせる例が多い。
4. **「→」で関係をつなぐ。** 同じ行の後半、次の行、下部のまとめ枠などに置く。通常文では黒、強調する後半だけ青にする使い方がある。
5. **括弧の補足は主文より弱い位置に置く。** 本文の続きや字下げした行を使用する。

内容を別のものへ差し替える場合の書式例：

```text
■ 【小見出し】                    青・17 pt・太字
• 【通常の説明】 → 【強調箇所】    黒・16 pt ＋ 一部だけ青・太字
    • 【条件・例外の補足】        一段下げ、必要箇所だけ赤・太字
```

この例は書式を示すもので、実際に発表する内容の案ではない。

## 7. 青・赤・黒・グレーの役割

| 色 | 代表的な色コード | 観察できた使い方 |
|---|---|---|
| 本文の黒系 | `#282629` | タイトル、通常本文、通常数値、ページ番号 |
| 基本の青 | `#3E7EC7` | 要点文、小見出し、文中の重要語、まとめ、選択した数値・項目 |
| 赤 | `#E02B2B` | 注意・例外、対比する側の数値、読み違えやすい条件、図中の枠など |
| 補足のグレー | `#6B7A88` | 図の説明、出典・図番号、補助的な注釈 |
| タイトル帯 | `#F3F4F6` | ページ上端の背景帯 |
| 表の見出し背景 | `#2B5581` | ヘッダー行。文字は白 |
| 表の交互行背景 | `#EDF3F7` | 白と交互に使って行を追いやすくする |
| まとめ枠の背景の例 | `#EAF1FA` | 薄い青。枠線は青 |

### 青の使い方

- **構造を示す青**：要点文と小見出しで、読む順序を作る。
- **文中の強調の青**：重要な単語・数値・短い節だけに使用する。
- **表の強調の青**：特定のセルや行内の項目を太字の青にする。表全体を青文字にしない。

### 赤の使い方

- 基本の本文色にはしない。
- 青と対比させる数値や、見落としてほしくない補足に限定して使用する。
- 図中の対象を囲う枠として使われる例もある。
- **赤が常に「悪い」、青が常に「良い」という一律のルールではない。** 比較対象を区別する色としても使われている。
- 図表の系列色と本文の強調色が関係するときは、キャプションや凡例で対応を説明する。

文中の赤・青の機能は実際の使用例からの観察であり、ファイルに明文化された規約ではない。

## 8. 図・表の配置パターン

### A. 本文を横幅いっぱいに使う

代表例：4枚目。タイトルと要点文の下に、小見出しと箇条書きを縦に配置。小見出しは同じ左端に揃える。図のための空の列を残さない。

### B. 左に本文、右に図を縦積みする

代表例：8、28枚目。

```text
タイトル帯
要点文（全幅）
┌────────────────┬─────────────┐
│ ■ 小見出し・本文          │ 図A                   │
│   • 補足                 │ 図Aのキャプション     │
│                          │                       │
│ ■ 次の小見出し・本文      │ 図B                   │
│                          │ 図Bのキャプション     │
└────────────────┴─────────────┘
```

- 本文が左側のおよそ半分強、図の領域が右側のおよそ4割という配置例がある。固定比率ではない。
- 代表的な左本文枠は幅12.0 cm、左端1.1 cm。
- 図は中央にまとめて浮かせず、右側の一定領域へ配置する。
- 2図ある場合は右側で上下に積み、説明文のまとまりから対応する図を追えるようにする。
- キャプションはそれぞれの図の直下。下部に図A・図Bの説明をまとめて離して置く作りではない。

### C. 上に本文、下に図を横並びにする

代表例：10枚目。

- 上半分〜中央を小見出しと箇条書きに使用。
- その下に2つの図を左右に並べる。
- 比較する図の上端や大きさを揃える。
- 2図に共通する色の説明などは、図の下にまとめる。

### D. 上に表、その右に凡例、下に本文

代表例：26枚目。

- 表は左側〜中央に大きく配置する。
- 表の右側に細い説明領域を確保し、単位、記号、色の意味を記載する。
- 表を説明する本文は下側に置き、上の表と横方向に競合させない。
- 必要な場合、本文の下に横長のまとめ枠を置く。

### E. 左に表と説明、右に複数の図

代表例：30枚目。

- 左列上部に表、左列下部にその補足を配置する。
- 右列には2図を縦に配置する。
- 各図の直下にグレーのキャプションを付ける。
- 異なる要素を混在させても、左列・右列の境界を維持する。

### F. 上に説明、下に全幅の表とまとめ

代表例：33枚目。

- 上側に小見出しと箇条書き。
- 下側に横幅を使った表。
- 表の下にまとめ枠を配置する。
- 表の見出しと本文の見出しで同じ青系統を用い、見た目を統一する。

## 9. 表の見せ方

- ヘッダーは濃い青地、白文字、太字。
- 本文行は白／薄い青グレーの交互塗り。
- 細い黒い罫線で行・列の境界を示す。
- 見出しと数値は中央揃えが多い。長い文字列では折り返す例がある。
- 文字サイズと列幅を揃えたうえで、選択したセルの文字だけを青または赤の太字にする。
- 強調は文字色で行う例があり、すべての注目セルを濃い背景で塗る作りではない。
- 表の右や近くに、色と記号の読み方を置く。

実測例：26枚目の表は列幅6.6／5.6／5.6 cm、行高0.62 cm。33枚目は4.2／4.8／7.1／7.1 cm、行高0.70 cm。これらはページごとの例であり、全表共通の寸法ではない。

## 10. 図とキャプションの見せ方

- 図自体は、軸・系列・凡例などを含む画像として配置される例がある。
- 図の周囲をカード状に囲う装飾は基本にしていない。
- キャプションは本文より小さく、グレーで配置する。
- キャプションには図の識別、記号・色の説明などを記載する形式が見られる。1行に収まらないものは複数行になる。
- 本文側には「上の図」「下の図」のような位置の参照を置く例がある。
- 図中の赤枠などは、本文中で注目させる箇所と対応させるために使用される。

適用時は図を縮める前に、本文列と図列の幅を調整する。キャプションの収容高さは行数分確保する。

## 11. 下部のまとめ枠

一部のページには、青い枠線・薄い青背景・小さめの角丸・薄い影の横長ボックスがある。本文中の全項目を囲むためではなく、ページの最後の一文を拾うために使用している。

- 左右は標準本文枠の端に近い位置へ揃える。
- 文頭に「→」を置く例がある。
- 本文は主に16 pt・太字。青い文の例と黒い文の例の両方がある。
- ページ番号とは別の高さを確保する。
- **すべてのページに必須の部品ではない。**

## 12. 表紙の扱い

表紙は通常ページとは別の構成。

- 白背景を大きく残す。
- 主題は左寄せの大きな黒い文字。
- 主題の下に細い横線を引く。
- 横線の下に所属・氏名・日付などの情報を左揃えで積む。
- 通常ページのグレーのタイトル帯や青い要点文は使わない。

## 13. 再現する部分と、そのまま写さない部分

### 再現する部分

- 4:3のサイズと共通の余白。
- タイトル帯、青い要点文、本文という縦方向の階層。
- 「■ 小見出し → 通常本文 → 字下げした補足」の段落構造。
- 青を基本の強調色、赤を限定した注目色、グレーを補助情報として使うこと。
- 図・表の近くに読み方を置くこと。
- 左右の列、図の上下、表と説明の位置関係を揃えること。

### 適用時に調整する部分

画像化した一部ページでは、長い小見出しの折り返し、狭いキャプション枠、表と後続見出しの接近が見られた。描画環境やフォントの影響もあるため、PowerPoint上でも必ず同じ状態になるとは断定しない。

再現対象は位置関係と階層であり、窮屈な折り返しまでそのまま写す必要はない。長い文章のために文字を縮め続けず、テキスト枠の幅・高さ、図との列配分、必要ならページ分割で調整する。

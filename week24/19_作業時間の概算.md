# Week24：作業内容と作業時間の概算

Week24の作業時間を、週報用に合計約27時間として整理する。
以下は作業内容に基づく事後的な概算配分であり、タイムトラッキングによる実測値ではない。
プログラムの実行ログから得られる実験時間とは区別する。

| 内容 | 時間 |
|---|---:|
| Raspberry Piの環境構築・メモリ保護・SSH切断対策 | 4時間 |
| 各フレームワークへのユークリッド距離回路の実装・動作確認 | 8時間 |
| 評価項目・測定条件の整理、動作しない方式の原因調査 | 3時間 |
| 順次実行プログラム、CSV／JSON保存・結果回収の実装 | 4時間 |
| 比較測定の実行・結果確認・統計整理 | 3時間 |
| 処理時間・メモリ・証明サイズの比較／個別グラフ作成 | 2時間 |
| MDへの結果整理・Issue整理・発表スライド作成 | 3時間 |
| **合計** | **27時間** |

## 対象範囲

Week24で行ったPi評価、評価用の実装・自動化、結果整理と資料化を対象とする。
Week23で行ったNova／HyperNovaの調査・実装は、この27時間に含めない。
Week24で行ったNova／HyperNovaのPi評価や、その結果の資料化は含める。

## 週報への記載例

> 作業時間：約27時間（概算）。Raspberry Pi上でのZKPフレームワーク評価、
> ユークリッド距離回路の実装、メモリ保護と順次測定の自動化、
> CSV／JSONへの結果保存、比較グラフと発表資料の作成を実施した。

実測した9構成の比較測定工程の合計は約31分17秒であり、上記の作業時間とは異なる。
実験工程の実測値は[実験所要時間CSV](slides/実験所要時間.csv)を参照する。

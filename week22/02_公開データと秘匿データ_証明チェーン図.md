flowchart LR

## nullifier rootが二重参加を防ぐ流れ

```mermaid
sequenceDiagram
  participant A as 端末A
  participant N as 再帰集約回路
  participant B as 端末B
  participant C as 最終proof

  A->>N: proof A + oldRoot
  Note over N: Aが登録済みか確認\noldRootのAスロットが未使用(0)か確認
  N->>N: Aのnullifierを記録してroot1を作る
  N->>B: proof Aを内包した状態(root1, count)
  B->>N: proof B + root1
  Note over N: Bの開始root == root1 を強制
  N->>N: Bのnullifierを記録してroot2を作る
  N->>C: root2 + 合計count + 最終ZK proof
```

同じ端末Aがもう一度参加しようとしても、`root1` ではAのスロットがすでに
未使用値 `0` ではないため、次のproofを作れない。

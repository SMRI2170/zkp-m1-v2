# Nova発表用スライド文面

以下は、スライドへそのまま貼れる文面である。改行位置を含めて記載する。

## スライド1：Novaの現状

### タイトル

```text
Novaによる逐次的な観測集約
```

### 本文

```text
各端末の観測を1件ずつ追加し、
整合件数と異常件数を更新する

3ステップのIVC proof生成・検証を確認
Android実機でも動作を確認

ただし現状は、RSSI整合と件数更新のPoC
登録端末確認と二重計上防止は未接続
```

## スライド2：本番proofまでに必要な接続

### タイトル

```text
Novaを本番経路へ接続するための残課題
```

### 本文

```text
1. 実leaf proofを固定鍵で検証する
   端末の観測・署名・freshnessを束縛

2. 登録端末だけを受理する
   memberRootで端末鍵を確認

3. 同じ端末の再計上を防ぐ
   nullifierRootをstepごとに更新

4. 最終proofをEVMで1回検証する
   Decider proofとV1 ABIを接続
```

```text

```

```text

```

```text

```

## スライド3：採用判断

### タイトル

```text
Novaの採用判断
```

### 本文

```text
逐次状態更新には適している

一方で、既存leaf proofの接続と
EVM向け最終proofは別途実装が必要

次は10ステップ程度で、
時間・メモリ・proofサイズ・gasを比較する
```

### 発表時の一言

```text
Novaは集約処理を軽くできる候補です。
ただしNovaだけで端末の真正性やEVM検証が完成するわけではありません。
その接続部分を実装・評価してから採用を判断します。
```

# 現在スマホで実装できる ZKP フレームワーク（検証反映版）

作成日: 2026-07-22 / 目的: 「今、スマホ（iOS/Android・特に Flutter）でオンデバイス証明を実装できる」
フレームワークを、**本プロジェクトで実際に検証した事実**を反映して整理する。
関連: week19/02〜03（調査）・08（Mopro PoC）・09（処理時間比較）。

## 結論（3分類）

| 区分 | フレームワーク | 根拠（この案件で確認したこと） |
|---|---|---|
| **実装できる（実証済）** | circom/Groth16（rapidsnark） | アプリで動作＋Mopro で APK までビルド確認。native 証明 ≈0.01s |
| **実装できる（実証済）** | Noir/UltraHonk（Barretenberg bb） | 回路 proof→verify 確認。native 証明 ≈0.13s。Android は Zig 必須 |

## 1. circom / Groth16（rapidsnark）── ◎ 本命・実証済

- **状態**: **このアプリで実際に動く**。`flutter_rapidsnark`＋`circom_witnesscalc` でオンデバイス証明。
  今回 RSSI 整合回路を追加し、**選択式でビルド（APK 233MB）まで確認**。
- **性能（実測・デスクトップ x86_64）**: rapidsnark(native) の証明生成 **≈0.01s（10ms）**（649制約の小回路）。
- **配布**: Flutter は既存構成、または **Mopro の circom アダプタ**で標準化（Mopro PoC で APK 実証済）。
- **弱点**: 回路別トラステッドセットアップ（★1）が必要。
- **判定**: **今すぐ実装できる唯一の“実証済み”本命**。

## 2. Noir / UltraHonk（Barretenberg）── ◎ 実装可・ただしAndroidにZig

- **状態**: Noir 回路の **proof→verify を確認**（bb 5.0.0）。モバイルは **Mopro の noir アダプタ**経由。
- **性能（実測・デスクトップ）**: bb(native) の証明生成 **≈0.13s（130ms）**。証明サイズ **14.6KB**。
- **Android の壁（確認済）**: barretenberg が **Zig の libc++** を要求（NDK と ABI 非互換）。
  → **Android ビルドには Zig 導入が必須**（iOS は比較的素直）。
- **利点**: 回路別セットアップ不要（★1 根治）。
- **弱点**: オンチェーン検証 gas 約2.4M（Groth16 の約7倍）、証明が大きい。
- **判定**: **実装可能。Android は Zig 前提**。準備不要を取るならこの経路。

## 3. halo2 / Plonky2 / Nova(Sonobe) ── ○ 実装可・自前FFI

- **状態**: いずれも Rust。**arm64 にクロスコンパイルは可能**だが、**Flutter 用の成熟プラグインが無く
  dart:ffi で自前配線**が要る（halo2 は Mopro 対応あり）。
- **向き**: halo2＝高度な回路、Plonky2＝準備不要・再帰、Nova＝**省メモリで端末側集約**。
- **判定**: 実装可能だが手間大。特に Nova は「多端末を端末で畳む」用途で将来有力。

## 4. Cairo / Stwo ── ○ モバイル実証は豊富・別エコシステム

- **状態**: モバイル証明の大規模実証あり（FibRace: 多機種で5秒以内）。iOS/Android SDK あり。
- **壁**: **検証が Starknet 前提**で、本案件の EVM＋gnark と土台がずれる。
- **判定**: スマホ証明は優秀だが、決済/検証レイヤの乗り換えが必要。

## 5. gnark / RISC Zero / SP1 ── ✕ 現状スマホ不向き

- **gnark**: Go。gomobile で載るが証明生成が重く**サーバ（集約 M2）向け**。
- **RISC Zero / SP1（zkVM）**: 端末単独の証明が重く**リモート prover 前提**でオンデバイスにならない。
- **判定**: 端末証明の選択肢ではない（将来の高性能端末で再評価）。

## この案件での推奨

- **今スマホで実装するなら circom/Groth16（rapidsnark）** ＝ 唯一の実証済み・最速・アプリに載っている。
- **トラステッドセットアップを消したいなら Noir**（Android は Zig 導入、gas 増は許容）。
- **端末側で多端末集約を攻めるなら Nova(Folding)**（自前 FFI）。
- gnark は集約サーバとして継続、RISC Zero/Cairo は今回は見送り。

→ 詳細な比較・実測・PoC は week19（02/03/06/08/09）、アプリ実装は `rapidsnark_app/`（RSSI 整合回路を選択式で追加済）。

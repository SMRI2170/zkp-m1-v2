# UAV Safety ZK — 画面・機能ガイド

> ゼロ知識証明 × ドローン接近検証アプリ

---

## アプリ概要

ドローンが自分から **30m 以内に接近したこと**を、GPS 座標などの個人情報を一切公開せずに暗号学的に証明するアプリです。  
「接近があったか」という真偽値だけを第三者に提示できます。

| 技術 | 役割 |
|---|---|
| Groth16 ZKP (rapidsnark) | デバイス内でゼロ知識証明を生成・検証 |
| OpenDroneID BLE | ASTM F3411-22a 準拠でドローンの Remote ID を自動受信 |
| YOLO v11 TFLite | リアルタイムドローン検知（ML Kit フォールバックあり） |
| Flutter / Riverpod | クロスプラットフォーム UI・状態管理 |

### 3つのタブ構成

| タブ | 内容 |
|---|---|
| 🏠 メイン | カメラ＋リアルタイム検知＋録画・ZK証明の実行 |
| 📊 詳細 | 証明結果・Public Signals・回路プロファイル選択 |
| 💻 ログ | タイムスタンプ付きコンソールログの閲覧 |

---

## 🏠 メインタブ

カメラビューをフルスクリーンで表示し、全操作を一画面に集約しています。

### ① ステップバー

```
BLE ──●── GPS ──●── 録画 ──○── 証明
 ✓         ✓       （次）
```

BLE → GPS → 録画 → ZK証明 の4ステップ進捗を画面上部に常時表示します。  
完了済みのステップは緑色になります。

### ② カメラプレビュー

- フルスクリーンのライブビュー
- YOLO が **800ms ごと**に推論を実行
- ドローンを検知するとバウンディングボックスをリアルタイム描画
- 録画中・ZK証明中は検知ループを自動停止

### ③ データカード

画面下部に2枚のカードを並べて表示します。

| カード | 内容 | データソース |
|---|---|---|
| ドローン | 緯度・経度・高度 | BLE 自動受信 または 手動入力 |
| あなた | 緯度・経度・高度 | GPS + 気圧計 |

それぞれ取得済みデータ件数をバッジで表示します（最大20件）。

### ④ 距離・時刻差チップ

ドローンと利用者の推定距離と時刻差をリアルタイム表示します。

| 状態 | 色 | 条件 |
|---|---|---|
| 安全 | 🟢 緑 | 距離 ≤ 30m かつ 時刻差 ≤ 5秒 |
| 超過 | 🟠 オレンジ | いずれかが閾値を超えている |

### ⑤ 録画コントロール

- **録画開始** → ライブ検知を停止してカメラ録画（mp4）を開始
- **録画停止** → YOLO でフレームを自動解析し UAV 検知結果を確定
- 解析中はプログレスバーを表示
- 録画後は **再録画ボタン**で撮り直し可能

### ⑥ ZK 証明ボタン

- ドローン座標・利用者座標・動画が**すべて揃ったときのみ**アクティブ（緑）
- 証明中は経過秒数をリアルタイム表示
- 完了後に判定結果カードを表示（緑: 接近なし / 赤: 接近あり）

## ドローンデータ取得

### BLE 自動受信モード

```
OpenDroneID BLE スキャン開始 (Service UUID 0xFFFA)
        ↓
BasicID (type=0)   →  UAS_ID を取得
        ↓
Location (type=1)  →  緯度・経度・高度・速度・飛行状態
        ↓
System (type=4)    →  オペレーター位置・エリア情報
        ↓
フォームに自動反映、履歴を最大 20件保持
```

- DJI 旧機種の Manufacturer Data（Company ID `0x2005`）にも対応
- Message Pack（type=0xF）は分解して各メッセージを個別パース
- 1秒ごとに再スキャン（ZK証明中・録画中は停止）

### 手動入力モード

BLE が受信できない場合はフォームに直接入力します。

| フィールド | 例 |
|---|---|
| 緯度 (Latitude) | `35.6895000` |
| 経度 (Longitude) | `139.6917000` |
| 高度 (Altitude m) | `120.0` |
| タイムスタンプ (Unix sec) | `1748217600` |

> デバッグ時は「デモ用：BLE スキップ」ボタンで疑似データを注入できます。

## UAV 検知

### モデル選択（優先順）

| 優先度 | モデル | 設定ファイル |
|---|---|---|
| 1 | VisDrone fine-tuned YOLO | `uav_visdrone_finetuned_config.json` |
| 2 | Roboflow UAV 専用 YOLO | `uav_roboflow_drone_config.json` |
| 3 | 汎用 YOLO | `uav_yolo11n_uav.tflite` |
| 4 | ML Kit フォールバック | ImageLabeler + ObjectDetector |

### 検知仕様

| 項目 | 仕様 |
|---|---|
| ライブ検知間隔 | 800ms ごとに `takePicture()` → YOLO 推論 |
| バウンディングボックス | `CustomPainter` で描画。ラベル＋スコア(%)を表示 |
| 重複除去 | NMS (IoU 閾値 0.45) |
| iOS | GPU Delegate 有効 |
| Android | CPU 2スレッド（GPU は一部機種で不安定なため無効） |
| UAV 判定キーワード | `drone` / `quadcopter` / `multirotor` / `uav` / `unmanned aerial vehicle` / `airplane` / `helicopter` |

## 録画 & 動画解析

```
① 録画開始
   ライブ検知を停止。カメラに mp4 を書き込み開始。
        ↓
② 録画停止
   最適ペア選択: 時刻差が最小のドローン/GPS ペアを履歴から自動選択。
        ↓
③ フレーム抽出
   0ms / 1000ms / 2500ms の3点サムネイルを一時ディレクトリに保存。
        ↓
④ YOLO 解析
   各フレームに YOLO 推論。検知結果のプレビュー画像（bbox 描画済み）を生成。
        ↓
⑤ 証拠確定
   UAV 検知フラグを確定。プレビューと検知ラベルを詳細タブに表示。
```

**補足**
- ML Kit フォールバック時: ObjectDetector で bbox 取得 → 領域を切り出し → ImageLabeler で再分類してラベル精度を向上
- 一時ファイル（サムネイル・クロップ・プレビュー）は解析後に `finally` ブロックで確実に削除

## ZK 証明パイプライン

```
Step 1: 入力構築 (ZkInputBuilder)
   ドローン座標・利用者座標・タイムスタンプ・UAV検知スコアを入力 JSON に変換
        ↓
Step 2: Witness 計算 (circom_witnesscalc)
   Circom コンパイル済みの .wcd グラフと入力 JSON から Witness バイト列を生成
        ↓
Step 3: Groth16 証明生成 (flutter_rapidsnark)
   .zkey を一時領域にコピーして groth16Prove() を実行。proof JSON を取得
        ↓
Step 4: 証明検証 (flutter_rapidsnark)
   verification_key.json を用いて groth16Verify() を実行。valid: bool を返す
```

全処理はデバイス内で完結します。

### 証明回路プロファイル（5種類）

| プロファイル | 内容 |
|---|---|
| **Base** | 距離と時刻のみ。最小構成。 |
| **Detection Flag** | UAV検知フラグ・スコア・クラスを追加。 |
| **Commitment** | Poseidon ハッシュで座標をコミットメント化。最高プライバシー。 |
| **Feature Classifier** | 外部抽出特徴量を小さな分類器で評価。 |
| **Time Series (20点)** | 録画中の最大20ペアの時系列データを評価。 |

### 公開される情報（Public Signals）

```json
[
  "1",  // within30:    30m 以内に入ったか
  "1",  // distance_ok: 距離閾値以下か
  "1"   // time_ok:     時刻差 5秒以内か
]
```

> 生の GPS 座標・飛行ルートは外部に出ません。  
> Commitment プロファイルは Poseidon ハッシュで座標を秘匿したまま証明に紐付けます。

## 📊 詳細タブ

| セクション | 内容 |
|---|---|
| ① 回路セレクター | 5種類のプロファイルをチップで選択。証明実行中はグレーアウト。 |
| ② UAV 検知結果 | 録画解析フレームのプレビュー画像とラベル・信頼度スコアを表示。 |
| ③ 判定要約カード | `within30` / `distance_ok` / `time_ok` の組み合わせで自動生成したメッセージを表示。プライバシー説明も併記。 |
| ④ Witness Inputs | ZK 回路に渡した入力 JSON を全文表示。緯度経度は E7 正規化済み整数値。 |
| ⑤ Public Signals | 証明検証後の公開信号を JSON で表示。Base: 3要素 / Commitment: 10要素 / Time Series: 21要素。 |
| ⑥ Proof JSON | Groth16 証明の `pi_a` / `pi_b` / `pi_c` を表示。第三者への提示・オフチェーン検証に利用可能。 |

### 色分けルール

| 色 | 対象 |

## センサー統合

### GPS (geolocator)

- 取得: 緯度・経度・高度（WGS84）、精度: `LocationAccuracy.best`、更新間隔: 1秒
- 利用: 利用者座標として ZK 証明入力に使用。履歴を最大20件保持し、録画時刻に最も近いスナップショットを自動選択

### 気圧計 (sensors_plus)

- 取得: 大気圧（hPa）、初回取得値を地表基準気圧として保存
- 利用: ISA モデルで相対高度を計算し GPS 高度を補完

```
altitude = 44330.0 × ( 1 − (P / P₀)^(1/5.255) )
```

### カメラ (camera plugin)

- 設定: `ResolutionPreset.medium`、`enableAudio: false`
- 利用: ライブビュー表示・YOLO 推論用フレーム取得・動画録画（mp4）の3用途
- 権限なし時はエラーメッセージと再試行ボタンを表示

### 権限要求フロー（起動時）

```
位置情報サービス確認 → Location 権限要求 → GPS ストリーム開始
    → Camera 権限要求 → Microphone 権限要求 → カメラ初期化
```

> カメラとマイクの権限ダイアログが同時に出ないよう、GPS 完了後に順番に要求します。

## まとめ

| 機能 | ポイント |
|---|---|
| **メインタブ** | カメラビュー上で BLE・GPS・YOLO・録画・ZK証明を統合。4ステップのプログレスバーで状態を常時表示。 |
| **BLE 受信** | OpenDroneID 準拠。BasicID / Location / System / Message Pack に対応。DJI 旧機種も解析可能。 |
| **YOLO 検知** | ライブ検知 (800ms) + 録画後フレーム解析の2段構成。3種類のモデルを優先順に自動選択。 |
| **ZK 証明** | Circom 5プロファイル × Groth16 をデバイス内で完結。生座標は外に出ず、真偽値だけを提示。 |
| **詳細タブ** | 回路選択・証明結果・UAV 検知プレビュー・Proof JSON を一覧表示。 |
| **コンソールログ** | BLE / GPS / YOLO / ZK の全イベントをタイムスタンプ付きで記録。色分けで視認性を確保。 |
